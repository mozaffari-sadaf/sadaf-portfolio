# Sadaf Mozaffari — Portfolio

A clean, responsive static portfolio website prepared for `sadaf.me`.

## Contents
- `index.html`: site content
- `styles.css`: responsive styling
- `favicon.svg`: site icon
- `.gitignore`: ignores local and potentially sensitive files

## Privacy
This is a fresh set of source files, not a clone or fork of the original private repository, so it does **not** contain that repository's Git history. The original site's direct personal phone number, email, binary photos, metadata sidecars and outdated JavaScript dependencies were excluded. Review all displayed professional information before sharing the site publicly.

## Publish on GitHub Pages
1. Open `https://github.com/mozaffari-sadaf/sadaf-portfolio`.
2. Choose **uploading an existing file** (or **Add file > Upload files**).
3. Upload `index.html`, `styles.css`, `favicon.svg`, `README.md` and, optionally, `.gitignore` from this folder. Commit directly to the repository's default branch (`master` if it remains unchanged).
4. Go to **Settings > Pages**, set **Source** to **Deploy from a branch**, choose the default branch (`master`) and `/(root)`, then Save.
5. Move the custom-domain setting away from the old repository: remove `sadaf.me` from the old `portfolio` repository's Pages settings if it is still configured there. Verify the domain in your GitHub account if requested.
6. In the new `sadaf-portfolio` repository under **Settings > Pages**, set the custom domain to `sadaf.me`. Check the DNS records in Namecheap and update them to GitHub Pages' documented records if needed, then enable **Enforce HTTPS** once available.

GitHub Pages will normally add a `CNAME` file when a custom domain is configured through its Pages settings. No domain binding is bundled in this ZIP to prevent a conflict with the old repository before migration.

**Note:** This is a redesign, not a pixel-perfect copy of the prior site. Confirm employer names, roles, dates and wording before publishing.
